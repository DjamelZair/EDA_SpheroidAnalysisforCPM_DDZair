A simulation that re-creates the spheroids we just measured

Which simulation knobs control the shape numbers we trust, and how strongly?

A Cellular Potts Model is a physics-style cellular simulation. Cells are voxel patches that grow, move, and stick together according to a few energy rules. The model has seven knobs (cell-cell adhesion, cell-medium adhesion, perimeter penalty, target volume, etc.). To find the right knob settings for a given drug condition, we (a) run the simulation across many knob combinations, (b) extract the same shape numbers from each run, (c) match those numbers to the real spheroid measurements. This page audits which knobs actually move the shape numbers, and how reliably the knobs can be recovered from a finite sample.

Snapshots from the simulation. Cells are coloured patches in a virtual dish; they push and pull on each other according to adhesion energies and grow toward a target size. Different knob settings produce different cluster shapes, and we read out the same six shape numbers from these as we read from real microscopy.

Which shape numbers carry signal?signal-to-noise per feature

For each shape number, this asks: how strongly does it move when you change a simulation knob, relative to its random run-to-run noise? Area and diameter dominate, the same two numbers the previous theme found reliable from microscopy. Elongation and roundness barely move with any knob.

How well can each knob be recovered?average recovery error per knob

Lower bar means the knob can be recovered more accurately from a finite simulation sample. Contact adhesion and neighbour adhesion are the easiest knobs to identify. Temperature (cellular noise) and target width are the hardest because their effects on shape are subtle.

These are the trajectories the simulation needs to match: the shape numbers extracted from real microscopy under three drug conditions. The next step (matching simulated to real distributions, with optimal transport) recovers the simulation knob settings that explain each drug condition.

Which knob drives which shape number?hover for value · gold-outlined cells are dominant drivers
Area is moved by nearly every knob (most strongly by target width and contact adhesion). Elongation and roundness barely respond to any knob. This matches the reliability finding from the previous theme: size features are the only channel through which simulation knobs can be inferred reliably on this dataset.

Global sensitivity indices

Sobol decomposition · main effect vs total effect

From the same 1,152-run sample, this is the formal sensitivity analysis (Sobol indices). For each knob: the dark bar is its standalone effect on shape; the lighter bar adds in interactions with all other knobs. Knobs where the lighter bar is much taller than the dark bar are entangled with others, meaning they cannot be identified independently from a single shape readout.
