SARIMAX residual stack

Hybrid forecasting on intermittent retail demand.

Gradient-boosted trees stacked on SARIMAX residuals across 823 retail series, with a held-out shrinkage sweep that reveals where the gain is real and where it isn't. Validation MAE drops 26% against the SARIMAX baseline; on test, the shrinkage sweep returns the verdict α* = 0 for the average series, a result the linear baseline alone could not deliver consistently.

The pipeline

8 stages · 1 feedback loop
Eight-stage flow from raw daily demand to the test verdict.Input → SARIMAX → Residuals → Feature Eng → ML Stack → Stacked Forecast → Shrinkage Sweep → Output

How it works

Per-stage breakdown
Stage 01

Input

823 daily retail series across 4 store-product groups (G1 to G4), with calendar and price covariates.

Stage 02

SARIMAX

Per-series Seasonal ARIMA fit. Acts as the linear baseline and the source of residuals for the booster.

Stage 03

Residuals

ε_t = y_t − ŷ_t^SARIMAX. The boosters learn structure that the linear model could not absorb.

Stage 04

Feature engineering

Lags, calendar features, group identifiers, price, and per-group aggregates fed to the booster.

Stage 05 · Highlight

ML stack

HGB (per-group + centered), Tree, XGB (centered), MLP (centered) trained on the residuals. 7 boosters compared.

Stage 06

Stacked forecast

Final forecast = ŷ_t^SARIMAX + α · ε̂_t^ML, with α swept on a held-out window.

Stage 07

Shrinkage sweep

α ∈ [0, 1] evaluated against the held-out window. The sweep reveals where the gain is real.

Stage 08

Output

Per-group RMSE, MAE, horizon MAE; sample forecasts; test verdict (α* = 0 for the average series).

The leaderboard

Validation RMSE · lower is better

Eight model families, ranked on validation RMSE.

HGB·pg (per-group) wins validation RMSE at 2.379, beating the SARIMAX baseline at 2.650. The Tree booster and centered HGB variant tie close behind. XGB sits one rung lower, MLP closes the bottom.

Boosters trained on residuals consistently outperform the linear baseline on the validation window. But the shrinkage sweep on test pulls α back toward 0 for the average series, meaning the gain doesn't always survive a true held-out evaluation.

A real win on validation does not always survive the shrinkage sweep. Always evaluate on the held-out window.
